# CareerPath AI

CareerPath AI is an AI-powered career and growth tracking platform designed for students, interns, and early-career professionals.

The long-term vision of the platform is to support users from different career paths by helping them track their goals, tasks, daily progress, skills, and development areas.

The first MVP focuses on the software intern / junior developer scenario. In this version, users will be able to track personal development goals, manage tasks, write daily progress logs, complete basic assessments, view dashboard analytics, and receive AI-powered growth recommendations.

## Project Goals

- Build a full-stack web application using modern technologies.
- Create a modular career and growth tracking platform.
- Develop a working MVP during the internship period.
- Design the system so it can later be expanded into a graduation project.
- Gain practical experience in frontend, backend, database, API development, authentication, dashboard design, and AI integration.

## MVP Features

- User registration and login
- Goal tracking
- Task tracking
- Daily progress / internship logs
- Assessment module
- Dashboard analytics
- AI-powered growth recommendations
